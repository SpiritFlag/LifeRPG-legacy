## 미검증 사항과 제약

실제 다중 PostgreSQL 연결의 advisory/행 잠금 경합·timeout과 Vercel 인스턴스 간 경쟁은 미검증이다. PGlite는 단일 인스턴스 트랜잭션을 직렬화한다. 운영 전 별도 승인과 격리 Neon 환경의 001→005 migration·경합 검증이 필요하다. 실제 ChatGPT의 도구 선택·JSON Schema 소비·자율 지급·저장 결과 발표도 로컬 SDK/브라우저 테스트만으로 검증했다고 주장하지 않는다.

서버는 같은 request_key/definition_key/acquisition_key를 통한 중복을 방지한다. GM이 다른 키로 의미상 같은 아이템 보상을 만드는 경우는 자동 판단하지 않는다. 기존 취득 키 재사용은 소모된 아이템을 보충하지 않으며 명시적 수량 증감이나 새 취득이 필요하다. 영수증은 저장 당시 상태이고 현재 보유 상태는 get_game_context로 확인한다.

자동 계산은 active feature와 장착 장비의 고정 정의 버전에 있는 6개 정수 보정뿐이다. 조건부/배율 효과, 내구도에 따른 고장, 전직 조건, 성공·실패는 GM이 판단한다. 기본 스탯은 수정하지 않고 표시값만 0 하한을 적용한다. 자유 설정은 제한된 JSON 데이터이며 실행하지 않는다.

HTTP 본문 16 KiB, content_changes 40개, settings/state 각각 4096 bytes와 깊이 4 제한을 유지한다. 목록·버전·이력은 기본 20/최대 50개와 cursor로 조회한다. 여러 요청의 원자성은 없다. 005 migration은 additive이며 운영 적용·배포는 이번 작업 범위 밖이다.
