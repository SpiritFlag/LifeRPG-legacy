## 미검증 사항과 제약

PGlite는 단일 인스턴스의 트랜잭션을 직렬화한다. 제출 경쟁의 버전·중복 판정은 확인했지만 실제 다중 PostgreSQL 연결의 잠금 경합·timeout·Vercel 인스턴스 경쟁은 미검증이다. 운영 반영 전 격리 Neon branch의 001→004 이관·경합 검증과 실제 수다방 도구 선택·발표 검증이 필요하다.

GM이 이야기 의미·성공·실패와 분기를 결정한다. branch label의 자연어 조건을 서버가 평가하지 않으며 새 키로 같은 의미의 이야기를 만드는 경우를 자동 검출하지 않는다. 안정된 생성 키와 기존 UUID를 재사용해야 한다. 사건 연결은 현실 사실을 이야기의 근거로 연결하는 행위이며 보상·퀘스트 완료는 별도로 GM이 지정한다.

본문 16 KiB, 요청당 퀘스트 operation 40개·판정 10개, 부모 유지 자식 100개의 제한이 있다. 큰 정리는 active 상태에서 나누어 준비할 수 있으며 여러 요청의 통합 원자성은 보장하지 않는다. 기본 요약과 상세 배열은 제한된 크기로 반환하고 cursor로 이어 읽는다. 004 schema가 새 맥락 조회·퀘스트 기능에 필요하며 migration은 어떤 이야기도 생성하지 않는다. 운영 적용은 별도 승인 대상이다.
